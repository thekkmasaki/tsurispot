# #ツリスポ釣果 UGCキャンペーン設計

> 目的: 釣り界隈No.1の ANGLERS が勝った「ユーザー釣果を主役化」を地域特化で。
> 一次動線は**自サイトの釣果投稿フォーム**（`/api/catch-report-ugc`）。X/Instagram の
> `#ツリスポ釣果` はリーチと社会的証明用。優秀作は中の人が引用RT＋サイト掲載で主役化する。

## 全体像
1. **投稿導線**: ユーザーは (a) サイトの釣果投稿フォーム、または (b) X/IGで `#ツリスポ釣果` を付けて投稿。
2. **収集**: サイト投稿は `recent_reports:global` に蓄積。X/IGのタグ投稿は中の人が手動で発見（X検索APIは予算外のため／`daily-engage-digest.mjs` の検索リンク経由）。
3. **主役化**: 優秀作を中の人が引用RT、サイトの「編集部ピック」やエリア別ランキングに掲載。投稿者名（`tsuriId` があれば `/users/[tsuriId]`）へリンク。
4. **好循環**: 掲載された投稿者が喜ぶ → さらに投稿・シェア → 新規流入。

## 月例フォトコン（運用ルール案）
- **応募方法**: 期間中に `#ツリスポ釣果` を付けてX/IGに投稿、またはサイトから釣果投稿。
- **テーマ例**: 「今月の大物」「初めての一匹」「映える釣果写真」など月替わり。
- **選考**: 中の人＋編集部が選定（大きさ・コメント・写真の魅力）。
- **発表**: 月初にサイト＆公式SNSで発表、優秀作を引用RT＋掲載。
- **賞品（将来）**: メーカー協賛のロッド/ルアー等。協賛が付くまでは「サイト掲載＋公式引用RT」を賞とする。

## 規約・法務上の注意（必ず順守）
- **著作権は投稿者に帰属**。応募＝「ツリスポが公式SNS・サイトに掲載・引用することへの許諾」とみなす旨を募集要項に明記する（無断転載はしない）。
- **景品表示法**: 賞品を出す場合は懸賞の限度額を確認する。
  - 一般懸賞: 取引価額5,000円未満は景品最高額=取引価額の20倍、5,000円以上は10万円（かつ総額は売上予定額の2%）。
  - オープン懸賞（購入不要・SNS応募のみ）は原則上限規制の対象外だが、最新の運用を確認する。
  - **賞品を出す前に必ず最新の景表法・各ガイドラインを確認**（本ドキュメントは目安であり法的助言ではない）。
- **各SNSのキャンペーン規約を順守**（X/Instagram のリポスト・懸賞に関するポリシー）。
- **個人情報**: 当選連絡はDM等で最小限に。写真に写り込んだ第三者・ナンバープレート等に配慮。

## 除外（応募対象外・掲載しない）
- 立入禁止区域・私有地への無断立入、危険行為（ライフジャケット無しの磯・無謀な夜釣り等）を助長する内容。
- 未成年者の単独危険行為、密漁・禁漁期/禁漁区・サイズ規制違反が疑われる釣果。
- 他人の写真の転載、AI生成の偽釣果、公序良俗に反する内容。
- 既存 `src/lib/moderation.ts` のNGワード・パターンに該当するもの。

## 実装の対応関係
- 投稿受け皿: `src/app/api/catch-report-ugc/route.ts`（自動公開・NGワード・レート制限）＋通報強化（`report-flag`・閾値2＋初回通報でDiscord通知）。
- 主役化(未実装・follow-up): 「編集部ピック」FEATUREDフラグ（DynamoDB `REPORT#{id}/FEATURED`）＋エリア別「今月の釣果ランキング」`/ranking/[area]`。
- 拡散: UGCカードのX/LINEシェアボタン（`catch-report-list.tsx`）。
- 発見支援: `scripts/sns/daily-engage-digest.mjs` が `#ツリスポ釣果` 検索リンクを毎朝配膳。

## 補足
- 本ドキュメントは運用設計であり法的助言ではない。賞品付き懸賞を実施する際は、実施前に景品表示法・各SNS規約の最新版を確認すること。
