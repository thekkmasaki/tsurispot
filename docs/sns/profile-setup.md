# SNSプロフィール設定ガイド（X / Instagram）

> 目的: bioからのクリックを自サイトPVに変換し、アカウントを「ちゃんとした釣り情報アカ」に見せる。
> bioリンクは新設した **`/ig` リンク集**（`src/app/ig/page.tsx`）に集約する（Linktree不要・PVも自サイトに落ちる）。

## bioリンク（UTM付き）
プロフィールのリンク欄には、流入元を分解できるよう **UTM付きの `/ig` URL** を入れる：

- **Instagram** のbio: `https://tsurispot.com/ig?utm_source=instagram&utm_medium=social&utm_campaign=bio`
- **X** のプロフィール: `https://tsurispot.com/ig?utm_source=twitter&utm_medium=social&utm_campaign=bio`

※ `/ig` ページ内の各ボタンは**内部リンクなのでUTMを付けない**（内部遷移でセッション属性を壊さないため）。UTMはこのbioのURLだけに付ける。

## bio文面（案）
数値は**最新の実値**を使う（ハードコードで古い数字を焼き込まない）。スポット数は `/spots` の表示値（＝`fishingSpots.length`）を確認して記載するか、数値を出さず定性的に書く。

- **X（@tsurispot_jp）** 例:
  > 🎣 全国の釣り場・釣果・旬の魚をまとめる釣り場情報サイト「ツリスポ」公式。今どこで何が釣れてる？を毎日発信／釣果クイズも。#釣り好きな人と繋がりたい
  > 🔗 tsurispot.com/ig
- **Instagram（@tsurispotjapan）** 例:
  > 🎣 日本の釣り場情報サイト「ツリスポ」公式
  > 全国の釣り場／今釣れる魚／みんなの釣果
  > 👇まずはここから
  > （bioリンクに上記URL）

### NG（虚偽・誇張は書かない）
- 実在しない実績・編集部プロフィールの虚偽（例:「兵庫県在住」等の事実でない記述）は使わない。
- スポット数などの数値は古い固定値を書かない（`2,700` 等の古い表記の再利用禁止）。

## ヘッダー画像
- 現状は手動で用意（釣り場写真＋「ツリスポ／全国の釣り場・釣果・旬の魚」のシンプルなバナー）。
- **follow-up**: OGルート（`src/app/api/og/route.tsx`）に `type=banner`（X 1500×500）を追加すれば動的生成できる（別PR予定）。

## Instagram ハイライト構成（案）
- 「釣り場の探し方」「今釣れる魚」「みんなの釣果」「釣りクイズ」— それぞれ数枚のカバー＋リール。
