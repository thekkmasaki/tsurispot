# GAS（釣果報告・お問い合わせ受付）更新手順 2026-11

`scripts/gas-catch-report.js` を更新しました。Google Apps Script はリポジトリから自動反映されないため、以下の手順で貼り替えてください（所要 5〜10 分）。

## 今回の変更点

- スプレッドシートの数式インジェクション対策（`=` `+` `-` `@` などで始まる投稿内容を文字列として保存）
- 共有キー（`SHARED_KEY`）による送信元チェック（ツリスポのサーバー以外からの偽投稿・偽メールを拒否）
- デバッグ用の `type: "echo"` 処理を削除

## 手順

1. **スクリプトを貼り替える**
   - 対象のスプレッドシートを開き、「拡張機能」→「Apps Script」を開く
   - 既存のコードを全て削除し、リポジトリの `scripts/gas-catch-report.js` の内容をそのまま貼り付けて保存（💾）

2. **スクリプト プロパティ `SHARED_KEY` を設定する**
   - 左メニューの「⚙ プロジェクトの設定」→ 下部「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ: `SHARED_KEY`
   - 値: 推測されにくいランダムな文字列（32文字以上推奨。例: パスワード生成ツールで英数字40文字）
   - 「スクリプト プロパティを保存」
   - ※ この値はチャットやメールに貼らず、手順4で Claude に渡す方法を相談してください

3. **同じURLのまま新しいバージョンとしてデプロイする**
   - 右上「デプロイ」→「デプロイを管理」
   - 既存のウェブアプリのデプロイを選び、鉛筆（編集）アイコン
   - 「バージョン」で **「新バージョン」** を選び、「デプロイ」
   - ⚠️「新しいデプロイ」を作るとURLが変わってしまうので使わないこと（URLが変わると `GAS_CATCH_REPORT_URL` の変更も必要になる）

4. **Claude に「GAS 更新した」と伝える**
   - Claude が App Runner の環境変数 `GAS_SHARED_KEY` に手順2と同じ値を設定し、再デプロイ後にお問い合わせ・釣果投稿の通知が届くことを確認します

## 注意

- 手順2〜3が終わってから手順4（`GAS_SHARED_KEY` 設定）が完了するまでの間は、サーバーからの送信にキーが付かないため **GAS 側で拒否され、通知メールとシート記録が止まります**。サイト側の投稿・お問い合わせ自体は受け付けられ、控えは Redis に残ります。間を空けずに進めるか、手順2（`SHARED_KEY` 設定）だけ手順4の直前に行ってください。
- `SHARED_KEY` を設定しなければ、従来どおりキー無しで受け付けます（数式対策のみ有効）。
