# ツリスポ（TsuriSpot）

**https://tsurispot.com**

ツリスポ（TsuriSpot）は、日本全国の釣り場（堤防・漁港・磯・砂浜・河川・湖など）を探せる無料の釣り情報サイトです。
釣れる魚・ベストシーズン・駐車場やトイレの有無・難易度・釣り禁止情報を、スポットごとにまとめています。

> **ご注意**: 「釣りスポ」（tsurispot.jp）とは別のサイトです。本リポジトリは tsurispot.com（ツリスポ）のソースコードです。

## 主な機能

- **釣り場検索**: 都道府県・市区町村・釣り場タイプ・設備（駐車場・トイレ等）・地図から探せる
- **スポット詳細**: 釣れる魚と時期、難易度、設備、ルール（投げ釣り・ルアー・コマセの可否など）、釣り禁止情報（根拠となる一次情報のURLと確認日つき）
- **魚種図鑑**: 釣り方・旬・釣れるスポット
- **潮見表**: 観測地点別の満潮・干潮
- **月別・季節別ガイド**: 今の時期に釣れる魚とおすすめの釣り方
- **釣り方ガイド**: サビキ・ちょい投げ・エギング・ウキ釣りなど
- **釣果投稿**: ユーザーによる釣果の投稿

## AI・検索エンジン向けの情報

- [llms.txt](https://tsurispot.com/llms.txt) — サイト概要
- [llms-full.txt](https://tsurispot.com/llms-full.txt) — 全魚種一覧と都道府県別ファイルの索引
- `https://tsurispot.com/llms/{都道府県}.txt` — 都道府県ごとの全スポット（1スポット1行）
- [sitemap.xml](https://tsurispot.com/sitemap.xml)

## 技術スタック

Next.js 16（App Router）/ TypeScript / Tailwind CSS v4 / shadcn/ui / Leaflet / microCMS（ブログ）

```bash
npm ci             # 依存パッケージのインストール
npm run verify     # 型チェック + Lint + テスト
```

スポット・魚種などのデータは `src/lib/data/` の TypeScript ファイルで管理し、ビルド時に静的生成しています。
